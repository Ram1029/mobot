## mobot
Этот бот предназначен для поддержки телеграмм-канала со своей предложкой и возможность создавать рассылки и задавать анонимно вопросы в специальный служебный чат.
### Настройка переменных окружения
Для корректного запуска контейнера создайте файл .env и заполните его по образцу example.env:
- **BOT_TOKEN** - токен телеграмм-канала
- **POSTGRES_PASSWORD** - пароль для базы данных постгрес
- **PROXY** - ссылка для прокси, оставьте пустым чтобы не использовать его
- **MAIN_CHANNEL_ID** - айди канала
- **MAIN_CHAT_ID** - айти служебного чата, должен быть форумом
- **ANNOUNCEMENTS_TOPIC_ID** - айди топика для создания рассылки
- **SUGGESTIONS_TOPIC_ID** - айди топика для модерации предложки
- **QUESTIONS_TOPIC_ID** - айди топика для ответа на вопросы
